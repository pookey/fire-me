# Commands

## Backend
```bash
cd backend && npm ci && npm run build    # esbuild bundle to dist/handlers/
```

## Frontend
```bash
cd frontend && npm ci
npm run dev       # local dev server (Vite)
npm run build     # production build (tsc + vite build)
npm run lint      # eslint
npm test          # vitest — MUST pass before deploying
```

## Infrastructure
```bash
cd infrastructure && npm ci
npm run build     # tsc
npm run synth     # CDK synth
npm run diff      # CDK diff
npm run deploy    # CDK deploy
```

## Full deploy
```bash
./deploy.sh       # backend build → CDK deploy → frontend build → S3 sync → CloudFront invalidate
```

## Environment variables

### Deployment (`.env`, template in `.env.example`)
- `AWS_PROFILE` — AWS CLI profile
- `FINTRACK_DOMAIN`, `FINTRACK_HOSTED_ZONE_ID`, `FINTRACK_ZONE_NAME` — Route53 config
- `API_BASE_URL`, `COGNITO_CLIENT_ID` — auto-populated by `deploy.sh` after first deploy

### Frontend (`.env.production`, auto-generated by `deploy.sh` from CDK outputs)
- `VITE_API_URL` — API Gateway endpoint
- `VITE_USER_POOL_ID` — Cognito User Pool ID
- `VITE_USER_POOL_CLIENT_ID` — Cognito client ID

Primary AWS region: `eu-west-2` (CloudFront cert in `us-east-1`).
